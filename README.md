# Glioma Tumor Output Prediction via Deep Neural Network

A deep neural network (DNN) trained to predict oncological tumor behavior in PDGF-driven glioma systems from biological parameters.

## Project Overview

This project applies machine learning to computational oncology, training a DNN to predict three clinical endpoints of glioma tumor behavior:
- Tumor cell percentage (Gperc in code)
- Immune cell percentage (Nperc in code)
- Terminal time: Time in days when tumor reaches 5mm (Tterm)

from biological model parameters using simulation data generated by the TumorDyn finite-volume PDE solver.

## Model Architecture
Input Layer: 3 neurons (biological parameters)
Hidden Layer 1: 32 neurons (ReLU activation)
Hidden Layer 2: 32 neurons (ReLU activation)
Output Layer: 3 neurons (G%, N%, Ttime)
- Framework: PyTorch
- Language: Python
- Training: Supervised learning on in silico simulation data

## Results

| Metric | G% | N% | Survival Time (T) |
|--------|----|----|-------------------|
| R² | 0.9861 | 0.9865 | 0.9916 |
| MAE | 0.02066 | 0.03245 | 0.7776 days |
| RMSE | 0.02458 | 0.03868 | 1.0771 days |

Survival time was predicted with mean error under 0.78 days, representing less than 2% of the typical 42-56 day survival window modeled.

## Data

ABOUT THE DATASET
-----------------
125tumor_dataset.csv contains will contain 125 simulation data points 
generated via structured 5x5x5 Cartesian grid parameter 
sweeps using the TumorDyn finite-volume PDE solver developed 
by Dr. Xianyi Zeng (Lehigh University).

INPUT PARAMETERS
----------------
    - alpha_a  (chemoattractant production rate)
    - gamma_a  (chemoattractant degradation rate)
    - mu       (glioma cell lysis rate)

OUTPUT VARIABLES
----------------
    - Gperc    (tumor cell percentage)
    - Nperc    (immune cell infiltration percentage)
    - Tterm    (survival time in days)

INCLUDED FILES
--------------
    - 125tumor_dataset.csv   (60 simulations)
    - parameters.dat         (simulation parameters)
    - regression_125new.dat  (regression data)
    - x_mean.npy             (input normalization mean)
    - x_std.npy              (input normalization std)
    - y_mean.npy             (output normalization mean)
    - y_std.npy              (output normalization std)
    - train_indices.npy      (training split indices)
    - val_indices.npy        (validation split indices)
    - test_indices.npy       (test split indices)
